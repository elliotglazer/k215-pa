Universal rational Diophantine equation: current status
3 November 2026

The construction and its written universality proof are complete for the
polynomial in universal-rational-equation.json, SHA256
 be7347c439459759121cda9656eda501afd75ca48897aa0f0acf5f85f6a43b1f.
For every pair of ordinary nonnegative integer parameters e,n, it has a
rational zero in 878,664,928,321 witnesses exactly when the program with
code e halts on input n, in the effective universal numbering supplied.

The proof is universal-rational-end-to-end-proof.txt. The requirement-
by-requirement review is universal-rational-completion-audit.txt. The
hashes of the actual supporting files are in
universal-rational-proof-manifest.json. This is a written proof package,
not a proof-assistant certificate or independent mathematical review.

The main dependency chain is now explicit:

1. Cyclic elliptic carrier: elementary descent, torsion calculation and
   exhaustive height-bounded generator search.
2. Six-contact height estimate: an explicit discriminant-six fine cover,
   good reduction, bounded Hom field, CM/non-CM height estimates and
   theta-coordinate comparison. The exact fixed constants are bound to U.
3. Twenty-two linear prime forms: Green--Tao--Ziegler and the displayed
   upper-sieve argument supply the precise per-prime order conditions.
4. Pole completeness: the restricted pointwise argument for squarefree
   parameters 11 modulo 12, combined with the exact simultaneous descent.
5. The actual multiplication template: soundness from 1 and 2;
   completeness from 1, 3 and 4, with its fixed finite false-triple guard.
6. Natural halting and accuracy polynomials: complete interpreter and
   compiler arguments, with whole-artifact source binding.
7. Rational interpretation and ordinary integer bridges: the exact
   multiplication theorem discharges the conditional interpretation
   proof; the proximity argument forces the external integer parameters
   to equal the internal indices.
8. The final sum of squares combines the three relations using disjoint
   witness blocks. Its exact count is 878,664,928,321.

The final dependency review corrected the false assertion that an exact
matrix inverse has a precision-independent Laurent pole bound. The
adjugate argument instead gives 4M at precision 2^M. It preserves the
clearing bound 16mM used by the pointwise proof. The polynomial and all
its coefficients remain unchanged. The correction and 72 finite
matrix checks are recorded in the completion audit.

The completed route uses SIX contacts. The original five-contact
family's separate theta comparison was not completed and is not used.
The polynomial's huge fixed coefficient prescriptions have been proved
terminating, not expanded into decimal coefficient arrays. Their size
does not change the witness count. The numerical ZFC proof-search code
has not been compiled; its possible specialization follows from the
proved universal interface.

No Lean formalization of H10(Q) or the relevant pointwise theorem was
found in the inspected OpenAI formalization catalogue at revision

That repository check is an availability check, not a Lean axiom audit.
OpenAI describes the repository as research material at differing stages
of verification. The proof package here should not be described as a
Lean-verified result or as community acceptance of the preprints.

Older component notes and the generator retain historical status lines
about premises that were then unproved. The completion audit identifies
the subsequent proof supplying each premise. Metadata is not part of
the defining polynomial equations. Earlier master status/readme copies
were preserved in the work directory for provenance.
