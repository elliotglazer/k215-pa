A numerical guard from one height constant
2 November 2026

For the linear-prime multiplication certificate, let H be the constant
in the five-contact estimate, after all required enlargements of the
fixed exceptional prime set:

  h(t) <= H M_S(t)^24.

If A>=1 is any integer with A>=H, a valid forbidden-box cutoff is

  T=(48A)^13.                                          (1)

This makes the dependence of the final guard explicit. It does not
supply the missing numerical value of A and does not establish the
remaining completeness input.

Proof

Use the isomorphic curve

  C: y^2=x^3-(3-sqrt(2))^2 x

and the point R=(1+sqrt(2),2sqrt(2)) from elliptic-generator-proof.txt.
The generator P on the original curve corresponds to 2R on C. The
duplication estimate proved there is

  4h_x(Q)-log(392) <= h_x(2Q)
                   <= 4h_x(Q)+log(676),

where h_x(Q)=h(x(Q)), with h_x(O)=0. Iteration gives

  h_x(Q)-log(392)/3 <= 2 hat_h(Q)
                    <= h_x(Q)+log(676)/3.

Since h_x(2R)=log(41), invariance of canonical height under the fixed
isomorphism yields

  2 hat_h(P) >= log(41)-log(392)/3 > 1.                 (2)

The last inequality follows from e<3 and 41^3>392*3^3.

Suppose a false certificate has indices n1,n2,n3 and

  f=n1*n2-n3 != 0,   N=max |ni|,   alpha=24/25.

Each of its 27 slopes has height at most H |f|^alpha by the local
divisibility and five-contact estimate.

For each root point, the two rational components x0,x1 are ratios of
its three homogeneous coordinates. Each homogeneous coordinate is
a sum of three slopes. Hence

  h(xj) <= 6H |f|^alpha+2log(3),  j=0,1.

This holds also with the assigned zero x-components at O. The usual
height inequalities in Q(sqrt(2)) give

  h(x0+x1 sqrt(2))
     <= 12H |f|^alpha+4log(3)+(3/2)log(2).

The change from the original curve to C multiplies x by
(1+sqrt(2))^4, whose height is 2log(1+sqrt(2)). Applying the upper
canonical-height comparison on C gives

  2 ni^2 hat_h(P) <= 12H |f|^alpha+B,

where

  B=4log(3)+(3/2)log(2)+2log(1+sqrt(2))+log(676)/3 < 10. (3)

For a check avoiding unqualified decimal estimates, put
epsilon=1+sqrt(2). We have

  epsilon^12=19601+13860sqrt(2)<40000,
  e>8/3,
  3^84 * 2^9 * 40000 * 676^2 < 8^60.

The first inequality follows from sqrt(2)<10/7. The last is a direct
integer comparison, checked in this session. Together they give

  exp(6B) = 3^24 * 2^9 * epsilon^12 * 676^2 < e^60,

which proves (3).

Choose i with |ni|=N. A false triple has N>=1. Using (2), (3), H<=A,
and |f|<=N^2+N<=2N^2, we obtain

  N^2 < 24A N^(48/25)+10.

If N>=5 then 10<N^2/2, so

  N^(2/25)<48A,
  N<(48A)^(25/2)<=(48A)^13.

If N<=4, (1) already dominates N. Thus every false certificate is
inside [-T,T]^3.

All coordinates iota(k) for |k|<=T are computable rational tuples from
the explicit generator. The forbidden-product polynomial in
universal-rational-equation-status.txt can therefore be formed once
an actual integer A>=H is established. The polynomial degree and
coefficient sizes can be enormous but are fixed independently of the
ordinary integer input parameters e,n.

The cutoff proof uses the previously checked internal soundness of the
linear-prime certificate and the stated five-contact height bound.
It supplies no substitute for the height bound itself or for the
pointwise-converse input needed in certificate completeness.
